Why getHistory was not generated

The getHistory Azure Function is declared by HistoryHandler in the shared function-util dependency. Its @FunctionName annotation is valid and the Azure Functions Maven plugin can discover it.

The build environment is using JDK 17, while the project compiles for Java 21. The original build failed with “release version 21 not supported”. When the plugin scanned the existing Java 21 class files under JDK 17, it reported zero function entry points. This was a build JDK/bytecode mismatch, not a missing function implementation.

A clean diagnostic package compiled for Java 17 generated metadata for getHistory, keepAlive, and shutdown. Build with JDK 21 to use the project's configured Java version; no application code change is needed.
