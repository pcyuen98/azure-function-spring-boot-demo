Why Java 17 is configured

The Azure Functions Maven configuration for this project targets Java 17. The shared Maven parent was compiling the function and its shared function-util dependency for Java 21, so deployment rejected the artifact because its bytecode was newer than the configured runtime.

Setting the shared java.version to 17 makes Maven compile the modules for the same Java version used by the Azure Functions runtime. This keeps the application and its dependency compatible with Java 17.
